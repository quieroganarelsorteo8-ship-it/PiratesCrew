# Dirección artística

Cuatro fondos originales creados con la herramienta integrada de generación de imágenes, sin usar la API ni una herramienta alternativa. Archivos finales: `dist/assets/bahia.png`, `coral.png`, `volcan.png` y `tormenta.png`. Las piezas y controles son SVG, HTML y CSS interactivos.

## Prompts

Bahía: "Use case: stylized-concept. Create a premium mobile pirate puzzle game background illustration, landscape 3:2 composition. A spectacular sunlit Caribbean pirate island with lush rounded palm trees, turquoise crystal water, cream sandy beaches, colorful friendly pirate village, elaborate giant wooden pirate ship with ivory sails and purple skull flag in harbor, sparkling golden treasure chest on foreground rocks, distant rounded emerald mountains. Polished rich 3D animated feature quality, painterly finish, glossy warm materials, beautiful ambient occlusion, vibrant jewel colors, warm sunlight, high visual depth and exquisite inviting detail. Clear readable large forms, playful and luxurious, family friendly. Center-middle is calm ocean for game UI overlay, scenery clustered around edges and background. No UI, no grid, no jewels, no lettering, no logos, no text, no crown, no shields. This is a production website game background asset, not a screenshot."
